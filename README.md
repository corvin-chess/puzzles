<p align="center"><img src="https://readme-typing-svg.demolab.com?font=IBM+Plex+Mono&weight=700&size=18&color=8FA3D9&center=true&vCenter=true&width=420&height=40&duration=1&pause=1000000&letterSpacing=6px&lines=OVERVIEW" alt="Overview" /></p>

Planned Rust tooling to generate, verify, tag, and rate puzzles from Corvin games only. Intended surfaces: batch jobs that extract candidate tactics from finished games, uniqueness checks, theme tags, puzzle ratings, and exports into the [server](https://github.com/corvin-chess/server) database. Depends on [chess-core](https://github.com/corvin-chess/chess-core) for rules and [engine](https://github.com/corvin-chess/engine) for line verification. No puzzle source is in this repository yet.
